# KitBattleLite

Paper MC 的职业战争插件。

职业战争是一个快节奏自由 PVP 小游戏，玩家选择拥有专属装备的职业，在战场上尽可能击杀对手。

玩家打开地图选择页进入竞技场，从职业页挑一套装备，在免伤保护结束后互相击杀；击杀、连杀、K/D 实时显示在侧边栏。游戏没有目标，只需要战斗爽！

- 运行环境：Paper 1.20.4，Java 17
- 存储：纯 YAML，无数据库

## 项目特色

- **轻量化**：插件本体只提供运行框架，不包含职业数据及技能，可高度自定义。技能可额外定制插件并作为职业的装备分发。
- **GUI 职业编辑**：在游戏内 GUI 里直接摆物品即可，不需要手写配置。支持编辑职业和排版职业页。
- **职业与页面解耦**：页面只记录职业 id，同一个职业可以摆在多页多格，改一次全部生效；删职业时自动清掉所有引用。
- **职业预览和一键装备**：右键职业格可查看整套装备，左键直接装备并传送到战斗点。
- **药水效果支持**：职业装备可包含药水效果，编辑页有独立药水格可快捷编辑。选择职业时会将效果以无限时长叠加给玩家。
- **配置外置**：数值在 `config.yml`，文案在 `messages.yml`（支持 MiniMessage），职业与地图用服务端原生 YAML 序列化，可手动编辑。

## 快速开始

### 环境要求

| 项目 | 要求 |
| --- | --- |
| 服务端 | Paper 1.20.4（`api-version: 1.20`） |
| Java | 17 及以上 |
| 构建 | Maven 3.8+ |

### 构建

```bash
mvn clean package
```

产物位于 `target` 目录下，不依赖其他插件，可以直接使用。

### 安装与配置

1. 把 jar 放进服务端的 `plugins/` 目录并启动，自动生成 `plugins/KitBattleLite/` 存放配置。
2. 配置竞技场可职业，见 [管理员手册](#管理员手册)。
3. （可选）自定义基础配置和文案，见 [配置文件](#配置文件)。


## 玩法

### 进入与离开

- `/kbl open` 打开地图选择页。绿色玻璃表示没人，黄色表示有人，黑色表示未开放。
- 点击已开放的地图，将传送到出生点，清空背包与状态，切到冒险模式。
- 点「离开」或执行 `/kbl leave`，将退出地图，返回进入前位置并恢复所有状态。

> [!WARNING]
> 不建议部署至生存服，如果服务器崩溃将丢失玩家进图前数据。

### 选择职业

- 点第一格的箱子打开职业页。每页 28 个职业格，可翻页。
- 左键职业：装备整套内容，传送到战斗点，获得一段时间免伤，开始战斗。
- 右键职业：查看整套装备内容。

### 对局规则

- **免伤**：进图到选完职业前完全免伤；选完职业后按 `protection-seconds` 再给一段保护（默认 3 秒）。重生后同样回到免伤状态，直到再次选职业。
- **死亡**：所有状态重置，死亡与击杀计入战绩，连杀清零。重生回出生点、重新发放按钮，并短暂失明（`death-blindness-ticks`，默认 2 秒）。
- **广播**：发生击杀时，同图玩家看到击杀播报；被击杀者与击杀者各自展示标题。
- **限制**：竞技场内禁止丢弃物品（创造模式除外）；落地的箭立即消失，不可捡起。

### 界面显示

- 侧边栏：连杀数量、累计击杀、累计死亡、K/D，可在 `config.yml` 关闭。
- 玩家名下血量：所有参与者共用一块计分板显示，可在 `config.yml` 关闭。

## 管理员手册

### 权限

| 权限          | 默认 | 说明            |
|-------------|----|---------------|
| `kbl.admin` | OP | 管理命令：地图、职业、重载 |

玩家命令 `/kbl open`、`/kbl leave` 不需要权限。命令主名为 `/kitbattlelite`，别名 `/kbl`、`/kb`。

### 命令

| 命令                                    | 权限          | 说明                         |
|---------------------------------------|-------------|----------------------------|
| `/kbl edit [页码]`                      | `kbl.admin` | 打开页面编辑器，页码从 1 开始，省略即第 1 页  |
| `/kbl import <地图ID> <世界名>`            | `kbl.admin` | 导入一个世界作为职业战争地图             |
| `/kbl setworld name <显示名>`            | `kbl.admin` | 修改当前地图的显示名，支持 MiniMessage  |
| `/kbl setworld spawn`                 | `kbl.admin` | 把当前位置设为出生点（重生点）            |
| `/kbl setworld teleport`              | `kbl.admin` | 把当前位置设为战斗点（选完职业后传送）        |
| `/kbl setworld enabled <true\|false>` | `kbl.admin` | 开放或关闭地图，立即生效               |
| `/kbl kit delete <职业id>`              | `kbl.admin` | 删除职业，并清空所有页面引用，日志记录被清槽位    |
| `/kbl kit prune`                      | `kbl.admin` | 删除所有未被页面引用的职业              |
| `/kbl reload`                         | `kbl.admin` | 重读职业、地图、战绩与文案；会把在线参与者请出竞技场 |

`setworld` 系列按玩家所在世界反查地图，必须站在目标地图的世界里执行。所有参数支持 Tab 补全。

### 搭建一张地图

1. 确保世界已被服务器加载，或存在于服务器目录中。
2. `/kbl import <地图ID> <世界名>` 登记，ID 会成为 `arenas.yml` 的键与命令参数。
3. 进世界，站到选职业前传送的位置执行 `/kbl setworld spawn` 以将该位置设置为重生点。
4. 站到选职业后传送至的位置执行 `/kbl setworld teleport` 以将该位置设置为传送点。
5. `/kbl setworld enabled true` 开放。
6. 可选：`/kbl setworld name <名字>` 改显示名。

> [!NOTE]
> 未设置的重生点和传送点会被默认设置为世界的出生点；未设置的显示名默认世界名。

> [!NOTE]
> 由于未选择职业的玩家拥有保护，故应当适当设置隔离防止其进入战斗区。

### 编辑职业

1. `/kbl edit` 打开职业编辑框。可指定页码（不存在的页会被新建）。
2. 从背包把物品拖进 28 个格子：普通物品会立即变成一个新职业（id 为 `kit-1`、`kit-2`…），只有图标，内容为空；同一个职业可以复制图表后摆在多个格子。
3. 右键职业格进入职业编辑器。上面 41 格是套装内容（前 5 格是头盔、胸甲、护腿、靴子、副手，后面 36 格是背包）。最后一行中间可设置图标。
4. 在编辑器的药水格中放置药水，可设置药水效果。药水包含的**自定义效果**会以**无限时长**应用到选择该职业的玩家直至死亡或退出。
5. 点「保存」写回内存；关闭窗口或点「取消」丢弃这一次编辑。保存前会校验来源格子没有被别人改过，改过就放弃保存并提示。
6. 关闭页面编辑器时落盘 `kits.yml`。

> [!NOTE]
> 页面编辑器里 Shift 点击背包物品会放进第一个空格；「下一页」在最后一页时会新建下一页。

### 配置文件

都位于 `plugins/KitBattleLite/`：

| 文件             | 内容                                             |
|----------------|------------------------------------------------|
| `config.yml`   | 数值与开关，启用时读取                                    |
| `messages.yml` | 玩家可见文案，MiniMessage 语法                          |
| `arenas.yml`   | 地图：`world`、`name`、`enabled`、`spawn`、`teleport` |
| `kits.yml`     | 职业：`icon`、`contents`；页面：`slots` 里的职业 id        |
| `stats.yml`    | 每个 UUID 的 `name`、`kills`、`deaths`              |

`config.yml`：

| 键                           | 默认   | 说明                                |
|-----------------------------|------|-----------------------------------|
| `protection-seconds`        | 3    | 选完职业后的免伤秒数，0 为不保护                 |
| `death-blindness-ticks`     | 40   | 重生后的失明时长（20 tick = 1 秒），0 为不失明    |
| `sidebar.enabled`           | true | 是否显示侧边栏                           |
| `health-below-name.enabled` | true | 是否在玩家名下显示血量（会占用主计分板，服上已有 HUD 时可关） |

`messages.yml` 里尖括号中的占位符由插件填值；未配置的键会回退到插件内置文案。

配置修改后 `/kbl reload` 生效。

### 落盘与重载

- 自动落盘：地图导入与 `setworld` 修改、职业删除与 `prune`、页面编辑器关闭、击杀结算、插件关闭。
- `/kbl reload` 会关闭所有插件菜单、把在线参与者请出竞技场，然后重读 `kits.yml`、`arenas.yml`、`stats.yml` 与 `messages.yml`，最后重画地图选择页。
- `config.yml` 的数值在启用时注入，改完需要重启服务器。

### 注意事项

- 地图 ID 与职业 ID 都是 YAML 键，不能包含空格与点号。
- 地图顺序就是 `arenas.yml` 里段落的顺序，超出显示上限的部分不会出现在菜单里。
- 进图前的背包靠快照还原，服务器崩溃不会补发。
- 不要一边开着编辑界面一边手改 YAML，也不要编辑到一半执行 `/kbl reload`，可能产生不可控的覆盖。
